# blog
Учебный прототип блога на Node.js. Данные хранятся в JSON.
Без вёрстки: фокус на сервере, API и выводе данных.

## Установка зависимостей
1. Перейдите в папку `app`
2. Отройте консоль в папке (Shift + ПКМ → Open in Terminal)
3. Ввести код ниже
```bash
   npm install
   ```

## Запуск
1. Перейдите в папку `app\server`
2. Отройте консоль в папке (Shift + ПКМ → Open in Terminal)
3. Ввести код ниже
```bash
  node server.mjs
  ```
4. Открыть в браузере http://localhost:3000

На главной список статей, по клику открывается страница статьи.
